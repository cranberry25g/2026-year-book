미리보기
- PC: 오른쪽 미리보기가 화면 상단에 고정되어, 왼쪽 입력 내용을 스크롤하면서 실시간 확인할 수 있습니다.
- 모바일/태블릿: 상단의 '입력하기'와 '미리보기' 버튼으로 화면을 전환합니다. 입력 중에는 미리보기를 숨겨 키보드와 겹치지 않게 했습니다.

PNG 저장 시 이미지 비율과 이미지 위치/확대 조정 기능을 유지합니다.


고해상도 PNG 저장
- 입력 화면의 '저장 해상도'에서 기본(1600×1200), 2배(3200×2400), 3배(4800×3600)를 선택할 수 있습니다.
- 2배 저장을 권장합니다. 3배는 파일 용량과 브라우저 메모리 사용량이 커질 수 있습니다.
- 미리보기 크기와 편집 기능은 기존과 동일합니다.
