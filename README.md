# Yearbook 2026 — GitHub Pages

## 구성
첫 화면에서 두 가지 중 하나를 선택합니다.
- **2026 연말결산**: 프로필, 현재 최애, 장기간 좋아한 캐릭터, 대화가 가장 많았던 캐릭터, 가장 많이 웃게 한 캐릭터, 가장 많이 울게 한 캐릭터, 올해 최고의 문장, 마지막 한마디
- **올해의 캐릭터 어워즈**: 올해의 최애상, 올해의 얼굴상, 올해의 유죄상, 올해의 과몰입상, 올해의 인생 캐릭터상

## 주요 기능
- 캐릭터/문장 이미지 업로드
- 이미지 기본값은 4:3 프레임 안에 전체가 보이는 `contain`
- 이미지별 가로 위치, 세로 위치, 확대/축소 조정
- 캐릭터별 개별 코멘트 및 어워즈 수상 코멘트
- 실시간 미리보기
- 브라우저 자동 저장(localStorage)
- 각 페이지를 1600×1200px PNG 한 장으로 저장
- 하단 크레딧 `made by @cranberry25g`

## GitHub Pages 공개 방법
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 Save를 누릅니다.
6. 잠시 기다리면 공개 주소가 생성됩니다.

## 참고
- PNG 저장은 html2canvas CDN을 사용하므로 인터넷 연결이 필요합니다.
- 웹폰트는 Google Fonts에서 불러옵니다. 인터넷이 연결되지 않으면 대체 글꼴로 표시될 수 있습니다.
- 입력 내용과 이미지 데이터는 해당 브라우저의 localStorage에 저장됩니다. 서버로 전송되거나 다른 기기와 자동 동기화되지 않습니다.
- 이미지 위치 조정은 가로/세로 위치 및 확대/축소 슬라이더로 할 수 있습니다. 기본 이미지는 잘리지 않도록 전체 보기에 맞춰져 있습니다.
